# UI inspiration

Put screenshots and images that show the look we want in this folder (PNG or JPG). Name them by screen, for example:

- `home-1.png`, `checkin-story-1.png`, `checkin-review-1.png`
- `snapshot-1.png`, `patient-list-1.png`
- `general-colours-1.png` for overall mood, colours or typography

Optionally add a line per image to the list below saying what you like about it ("the calm colours", "the card layout", "big buttons").

**How the images are used:** they guide layout, spacing, colours and tone. The components themselves come from **shadcn/ui** (see decision #15 in [DECISIONS.md](../../DECISIONS.md)), so we match the feel of an image with library components and a theme, not by rebuilding it pixel for pixel.
